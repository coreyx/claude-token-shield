# Passive Cache Monitoring
 
Requirements:
 
- Does not create transcript entries.
- Uses terminal UI only.
- Non-intrusive.
- User configurable.
 
Examples:
 
[cache] Healthy (86%)
[cache] Confidence dropping (63%)
[cache] Cache may have expired
[cache] Model change detected
[cache] MCP configuration changed
 
Notification Levels:
 
- Informational
- Warning
- Critical
 
Potential Locations:
 
- terminal status line
- footer
- sidebar
- toast notifications
