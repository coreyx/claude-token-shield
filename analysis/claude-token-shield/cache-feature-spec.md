
# Cache Awareness Feature
 
Goal:
 
Help users understand likely cache status before submitting expensive prompts.
 
Primary Features:
 
1. /cache-check command
2. Passive cache monitor
3. Cache health estimation engine
4. Cache event history
5. Cost prediction system
 
Principles:
 
- Never claim certainty when certainty is impossible.
- Distinguish measured information from estimated information.
- Prefer confidence scores over binary hit/miss predictions.
- Avoid polluting the conversation transcript.
